# Digital Bank API

Uma API REST simplificada para um banco digital com foco em transferências de fundos, consulta de movimentações financeiras e notificações de clientes via RabbitMQ.

## 📋 Requisitos

- Java 17 ou superior
- Maven 3.6+
- Docker e Docker Compose
- Git
